# diet_mom
=======
# Diet Mom

ブラウザだけで動くダイエット支援のシングルページアプリです。プロフィールから **TDEE（総消費カロリー）** と **1 日の摂取目標** を推定し、食事・運動を日ごとに記録して **目標との差** をグラフで確認できます。

- **ステートレス**: サーバーやデータベースは使いません。データは `localStorage` に保存されます。
- **GitHub Pages 向け**: 静的ファイルとしてビルドして公開できます（`vite.config.ts` の `base: "./"` はサブパス配備用です）。

---

## できること

1. **プロフィール入力**  
   年齢・身長・体重・性別・**活動レベル**・目標体重・目標日を保存します。体重は更新してよく、保存された最新値で TDEE と摂取目標を **その日の基準日で再計算** します。

2. **摂取目標の算出**  
   - **BMR**: Mifflin–St Jeor 式  
   - **TDEE**: BMR × 活動係数（座りがち〜非常に活発の 5 段階）  
   - **必要な総減量カロリー**: \((現在体重 − 目標体重) × 7700\) kcal（体脂肪相当のよく使われる近似）  
   - **日次赤字（素案）**: 総減量カロリー ÷ 目標日までの日数（当日・目標日を含む）  
   - **安全上限**: 日次赤字が **750 kcal を超えないようキャップ**（`src/lib/dietMath.js` の `MAX_DAILY_DEFICIT_KCAL`）。キャップが効くと期限内に目標に届かない可能性があります。UI に警告を出します。  
   - **摂取目標**: \(TDEE −\)（キャップ後の日次赤字）。あわせて **最低摂取** の下限を適用（女性 1200 / 男性 1500 kcal／日）。  
   - 目標日が過去、または目標体重が現在体重以上のときは **維持モード**（赤字 0、摂取目標は TDEE と下限の大きい方に近い挙動）です。

3. **カレンダーで記録**  
   日付を開いて、その日の **食事（kcal）** と次の運動を入力します（過去〜未来の月へスクロール可能。未来の日は薄く表示）。

   - 徒歩 **1 km × 回数**
   - 自転車（ゆっくり目）**1 km × 回数**
   - ラジオ体操 **× セット**

4. **グラフ（縦軸 kcal、横軸日付）**  
   - **実効摂取** = 食事 kcal − 運動による推定消費 kcal  
   - **日次の差分** = 実効摂取 − その日の摂取目標（**プラスは食べすぎ寄り**）  
   - **折れ線**: 日次の差分、およびその累積  
   - **積み上げ棒**:  
     - 日次: 「目標以内の実効摂取」と「超過分」  
     - 累積: 各日までの \(\sum \max(0, 目標−実効)\) と \(\sum \max(0, 実効−目標)\) を積み上げ表示  

   グラフに載せる日付範囲は **今日まで** で、開始日は **約 420 日前** と **記録が最初にある日** のうち古い方です。

## 運動の換算（MET と時間の前提）

消費カロリーは **MET × 体重(kg) × 時間(h)** で近似しています。値は [Compendium of Physical Activities](https://pacompendium.com/) 系の公開情報と一般的な速度・時間の仮定を組み合わせた **固定モデル** です（個人差・地形・心拍などは反映されません）。

| 種目 | MET（固定） | 時間の決め方 |
|------|-------------|----------------|
| 徒歩 1 km | 3.3（およそ 3 mph 域の歩行に近い値として） | 1 km あたり **0.2 時間**（〜5 km/h のイメージ） |
| 自転車 1 km | 4.0（ゆっくりレジャー域として） | 1 km あたり **0.1 時間**（〜10 km/h のイメージ） |
| ラジオ体操 1 セット | 3.5（軽い体操として） | 1 セット **5 分**（5/60 時間） |

実装は `src/lib/dietMath.js` の定数を参照してください。論文やガイドラインに合わせて変更したい場合も、このファイルだけを触れば UI と計算の両方に反映されます。

## データについて（重要）

- **データはこのブラウザにのみ保存**されます。エクスポート機能はありません。
- **機種変更・ブラウザのアプリデータ削除・シークレットモード終了**などで記録が失われることがあります。画面末尾に控えめな注意書きがあります。
- **複数端末間の同期はありません。**

## 開発

### 前提

- Node.js 20 以上と npm を推奨します。

### package-lock.json

初回 `npm install` 後に `package-lock.json` が生成されます。**Git にコミットすることを推奨**します（CI の再現性のため）。未コミットの場合でも、サンプルの GitHub Actions は `npm install` でビルドします。

### セットアップとローカル実行

```bash
cd diet_mom
npm install
npm run dev
```

ブラウザで表示された URL（通常 `http://localhost:5173`）を開きます。

### ビルド

```bash
npm run build
```

成果物は `dist/` に出力されます。`npm run preview` でローカル確認できます。

### ユニットテスト

計算・日付まわりは **Node の組み込みテストランナー**のみで動かしています（ブラウザや Vite に依存しません）。

```bash
npm test
```

テストファイルは `tests/` にあります。実装の核は `src/lib/dietMath.js` と `src/lib/dates.js` です。

### TypeScript チェック（任意）

```bash
npm run check
```

## GitHub Pages で公開する例

1. リポジトリを GitHub に push します。
2. **Settings → Pages** で **GitHub Actions** をソースに選ぶか、本リポジトリ付属のワークフロー（`.github/workflows/pages.yml`）を有効にします。
3. `main` への push でビルドされ、`dist` が Pages に載ります。

**ユーザー／組織のサイト（`username.github.io`）ではなく、プロジェクトサイト（`username.github.io/repo/`）** の場合、`vite.config.ts` の `base` を **`/リポジトリ名/`** に変更してください（末尾スラッシュあり）。ルートドメインだけで配る場合は `base: "/"` が適切です。

## 設計メモ（実装を読む人向け）

- **純粋ロジック**は `src/lib/dietMath.js` に集約し、React は表示と `localStorage` 入出力に寄せています。
- **状態**は `src/storage.ts` のキー `diet-mom-v1` で JSON として保存します。
- **履歴の体重**は日別には保存せず、プロフィールの **最新体重** だけで各日の TDEE／摂取目標を計算しています（仕様を単純化）。日別体重までやる場合は `logs` または別テーブル相当のフィールドが必要です。
- グラフライブラリは [Recharts](https://recharts.org/) です。
